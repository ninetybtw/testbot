# Эзотерический бот на TorroCRM — тестовое задание

Механика по ТЗ:

1. Бот в Telegram спрашивает **полное имя**, **дату рождения** и **место рождения**.
2. Данные **записываются в карточку клиента** в TorroCRM.
3. На их основе бот выдаёт **бесплатный прогноз**: знак зодиака, восточный гороскоп, число судьбы, число имени, личный год, число места рождения и совет. В конце прогноза стоит предложение полного платного разбора.

Прогноз считается по правилам, а не придумывается: один и тот же человек в течение месяца получает тот же самый текст. Клиенты часто проверяют это, проходя бота дважды.

---

## Из чего состоит

| Файл | Что это |
|---|---|
| `src/forecast.js` | Движок прогноза: проверка ввода, зодиак, восточный гороскоп, нумерология, сборка текста |
| `src/worker.js` | Вебхук `/forecast` для TorroCRM на Cloudflare Workers (бесплатный тариф) |
| `torro/agent-prompt.md` | Готовые промпты для блока «AI Агент» в Torro (два варианта) |
| `demo.html` | Демо в браузере: чат с ботом и карточка CRM, которая заполняется по ходу диалога |
| `test/` | Автотесты (`npm test`) |
| `scripts/demo.js` | Прогноз в терминале: `npm run demo -- "Иванова Мария Петровна" 14.03.1990 Казань` |

---

## Шаг 1. Карточка клиента в TorroCRM

Подключите бота: **Каналы → Telegram** и токен от @BotFather.

В карточке клиента создайте поля (если в вашем тарифе нельзя создавать свои поля, используйте «Заметку» и напишите в промпте, что данные записываются туда):

| Поле | Формат | Кто заполняет |
|---|---|---|
| ФИО | `Иванова Мария Петровна` | AI-агент |
| Дата рождения | `14.03.1990` | AI-агент |
| Место рождения | `Казань` | AI-агент |
| Знак зодиака | `Рыбы` | AI-агент (вариант Б) или вебхук |
| Число судьбы | `9` | AI-агент (вариант Б) или вебхук |
| Прогноз выдан | `Да` | сценарий |

Стадии воронки: **Новый → Анкета заполнена → Бесплатный прогноз → Хочет полный разбор → Оплачено**.

## Шаг 2. Сценарий в конструкторе

Собирается в **Автоматизации** из стандартных блоков Torro:

```
СТАРТ (клиент нажал /start)
  └─ Отправить сообщение: «Здравствуйте! Я составлю для вас бесплатный персональный прогноз
     по имени, дате и месту рождения 🔮 Как вас зовут полностью — фамилия, имя, отчество?»
  └─ AI Агент (промпт из torro/agent-prompt.md, вариант А или Б)
       заполняет поля «ФИО», «Дата рождения», «Место рождения»
  └─ Условие: поля «ФИО», «Дата рождения», «Место рождения» заполнены
       └─ Смена стадии → «Анкета заполнена»
       └─ [Вариант А] Вебхук POST https://<ваш-воркер>.workers.dev/forecast
            тело: {"name": "{ФИО}", "birth_date": "{Дата рождения}", "birth_place": "{Место рождения}"}
          └─ Отправить сообщение: {forecast из ответа вебхука}
       └─ Смена стадии → «Бесплатный прогноз»
  └─ Условие: клиент написал «полный разбор» → Смена стадии «Хочет полный разбор»
       + передача менеджеру
```

**Какой вариант выбрать.** Публичной документации по API и вебхукам у TorroCRM нет. На сайте сказано, что сценарий можно ветвить по «ответу вебхука», но в тесте ещё нужно проверить, можно ли вставить поле из ответа в текст сообщения.
- Если можно — **вариант А**: точный, одинаковый расчёт; текст прогноза меняется в коде.
- Если нельзя — **вариант Б**: всё делает AI-агент внутри Torro, сервер не нужен. Подойдёт для показа механики, но модель может ошибиться в арифметике.

## Шаг 3. Вебхук прогноза (для варианта А)

Нужен бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/sign-up).

```bash
npm test                         # проверить, что всё работает
npx wrangler login
npx wrangler deploy              # выдаст адрес https://esoteric-forecast.<ваш-ник>.workers.dev
npx wrangler secret put API_KEY  # необязательно: ключ, чтобы чужие не дёргали вебхук
```

Без командной строки: **Cloudflare → Workers & Pages → Create → Hello World → Edit code**. Вставьте содержимое `src/forecast.js` и `src/worker.js` (как два файла) и нажмите **Deploy**.

### Запрос

```bash
curl -X POST https://esoteric-forecast.<ник>.workers.dev/forecast \
  -H 'Content-Type: application/json' \
  -d '{"name":"Иванова Мария Петровна","birth_date":"14.03.1990","birth_place":"Казань"}'
```

Названия полей можно присылать по-разному: `name` / `full_name` / `fio`, `birth_date` / `dob` / `date`, `birth_place` / `place` / `city`. Подходят JSON, форма и GET-параметры. Если с ключом: заголовок `X-Api-Key` или параметр `?key=`.

### Ответ

```json
{
  "ok": true,
  "forecast": "🔮 Мария, ваш бесплатный прогноз готов\n\n♓ Знак зодиака: Рыбы ...",
  "full_name": "Иванова Мария Петровна",
  "first_name": "Мария",
  "birth_date": "14.03.1990",
  "birth_place": "Казань",
  "zodiac": "Рыбы",
  "element": "Вода",
  "eastern_year": "Металлическая Лошадь",
  "life_path_number": 9,
  "name_number": 5,
  "soul_number": 5,
  "personal_year": 9,
  "place_number": 5
}
```

Если данные некорректны, вебхук вернёт HTTP 422 и готовую фразу, с которой бот переспросит клиента:

```json
{ "ok": false, "error": "bad_date", "message": "Такой даты не существует. Проверьте день и месяц, например 14.03.1990." }
```

Коды ошибок: `bad_name`, `bad_date`, `bad_place`.

### Как поменять тексты

Все формулировки лежат в начале `src/forecast.js` в виде таблиц: `SIGNS`, `LIFE_PATH`, `PERSONAL_YEAR`, `PLACE_NUMBER`, `ADVICE`. Предложение платного разбора задаётся переменной `UPSELL_TEXT` в `wrangler.toml`, код для этого трогать не нужно.

## Демо для клиента

Откройте `demo.html` через локальный сервер (`npx serve .` или `python3 -m http.server`) и перейдите на `http://localhost:8000/demo.html`. Слева — чат с ботом, справа — карточка клиента, которая заполняется по мере ответов и меняет стадию.
